# CVez — Frontend (React + Vite + Tailwind CSS)

Modern single-page application built with React, Vite, and Tailwind CSS for interactive CV tailoring, ATS match score visualization, and PDF downloads.

## 🎨 Features
- **Sleek Dark Mode & Glassmorphism UI**: High quality visuals with Google Fonts (Inter + Outfit) and micro-interactions.
- **Drag & Drop File Upload**: Supports PDF and DOCX uploads with client-side file size & extension checking.
- **Job Description Presets**: Quick-fill template buttons for Software Engineer, AI/ML Engineer, and Product Manager roles.
- **AI Controls**: Provider selection (Gemini, OpenAI, Anthropic) and custom prompt focus directives.
- **Real-Time Stepper & Result Viewer**: Interactive progress animation, ATS match score gauge, tabbed section previews, and instant PDF download.

## 🚀 Getting Started

1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the Vite development server:
   ```bash
   npm run dev
   ```
   App will open at **`http://localhost:5173`**.

4. Build for production:
   ```bash
   npm run build
   ```
